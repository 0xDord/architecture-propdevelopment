# architecture-propdevelopment

## Классификация данных по стандартам ISO/IEC 27001 и 27002

### 1. ПУБЛИЧНЫЕ ДАННЫЕ

- **Каталог объектов недвижимости**
- **Информация о жилых комплексах**
- **Публичная информация о компании**

Риски (наиболее релевантные):
- **Искажение данных**: неверные цены/статусы/планировки → ввод клиентов в заблуждение — оценка: значительный
- **Потеря данных**: недоступность витрины, удаление каталога/медиа → падение лидов и SEO — оценка: значительный
- **Обесценивание данных**: массовое копирование контента конкурентами/мошенниками — оценка: незначительный

### 2. ВНУТРЕННИЕ ДАННЫЕ

- **Операционные данные**:
  - Логи работы систем
  - Технические метрики производительности
  - Статистика использования приложений
  - Данные о резервном копировании

- **Бизнес-аналитика**:
  - Статистика продаж (без персональных данных)
  - Аналитические отчёты по объектам
  - Тренды рынка недвижимости
  - Эффективность маркетинговых кампаний

- **Внутренняя документация**:
  - Процедуры и инструкции
  - Техническая документация
  - Политики безопасности (не секретные)

- **Данные о сотрудниках**:
  - ФИО сотрудников
  - Должности
  - Контактная информация для внутреннего использования
  - Данные о доступах к системам

Риски (наиболее релевантные):
- **Утечка данных**: публикация логов с токенами/внутренних адресов → облегчение атак — оценка: критический
- **Искажение данных**: подмена/манипуляция метрик и отчётов → неверные управленческие решения — оценка: значительный
- **Некачественные данные**: шумные, несогласованные логи → ложные алерты, слепые зоны — оценка: значительный
- **Потеря данных**: отсутствие логов/метрик → невозможность расследований — оценка: критический

### 3. КОНФИДЕНЦИАЛЬНЫЕ ДАННЫЕ

- **Персональные данные клиентов**
- **Персональные данные собственников**
- **Финансовые данные**
- **Данные о сделках**
- **Системные данные**

Риски (наиболее релевантные):
- **Утечка данных**: ПДн, детали сделок/платежей → штрафы, репутационный ущерб, мошенничество — оценка: критический
- **Искажение данных**: изменение реквизитов, сумм, статусов прав → финансовые потери/споры — оценка: критический
- **Потеря данных**: утрата карточек клиентов/договоров → срыв сделок и простоев — оценка: критический

### 4. СЕКРЕТНЫЕ ДАННЫЕ

- **Критические финансовые данные**
- **Критические системные данные**
- **Стратегическая информация**
- **Данные соответствия требованиям**

Риски (наиболее релевантные):
- **Утечка данных**: приватные/мастер‑ключи, корневые сертификаты → компрометация сервисов — оценка: критический
- **Потеря данных**: утрата ключей/резервных кодов → невозможность расшифровки/восстановления — оценка: критический
- **Искажение данных**: подмена сертификатов/политик → MITM и бэкдоры — оценка: критический
